Steganography — kompletny frontend

Zawartość: HTML, CSS, JavaScript oraz wszystkie lokalne ikony. Pliki skopiowane bez zmian z aktualnego projektu. Bez backendu, sekretów i historii Git.

Podgląd lokalny: w tym katalogu wykonaj: python3 -m http.server 8080
Potem otwórz http://localhost:8080/

Interfejs oczekuje /api/crypt i /api/decrypt. Algorytmy/backend nie są częścią paczki. Opcja ?demo=1 służy wyłącznie do prezentacji stanów UI; nie wykonuje prawdziwej steganografii.
